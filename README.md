# حسابداری روزانه — PHP + SQLite + DaisyUI

وب‌اپ فارسی و راست‌چین برای ثبت درآمد، هزینه، مدیریت حساب بانکی/صندوق، انتقال وجه، گزارش‌ها و پشتیبان‌گیری.

## نیازمندی‌ها
- PHP 8.1 یا جدیدتر
- افزونه‌های `pdo_sqlite` و `sqlite3` فعال
- هاست DirectAdmin یا cPanel
- اتصال اینترنت برای بارگذاری DaisyUI/Tailwind و کتابخانه‌های سمت مرورگر از CDN

## نصب روی هاست
1. فایل ZIP را استخراج کنید.
2. محتویات پوشه `hesabdari-rozane-php` را در `public_html` یا یک زیرپوشه دلخواه آپلود کنید.
3. مطمئن شوید PHP افزونه `pdo_sqlite` را دارد.
4. پوشه `storage` باید برای PHP قابل نوشتن باشد. اگر لازم شد مجوز آن را روی `755` یا با توجه به تنظیمات هاست `775` بگذارید؛ از `777` استفاده نکنید مگر پشتیبانی هاست ضرورت را تأیید کند.
5. سایت را باز کنید. در اولین اجرا، صفحه ساخت مدیر نمایش داده می‌شود.
6. نام کاربری و رمز عبور قوی تعیین کنید. رمز عبور به‌صورت هش ذخیره می‌شود.
7. پس از ورود، از «حساب‌ها» حساب‌های بانکی و صندوق نقدی خود را اضافه کنید.

## نکات مهم
- پایگاه داده به‌صورت خودکار در `storage/accounting.sqlite` ساخته می‌شود.
- تاریخ تراکنش در پایگاه داده به‌شکل استاندارد میلادی ذخیره و در رابط کاربری با تقویم شمسی نمایش داده می‌شود.
- مبلغ‌ها به تومان و به‌صورت عدد صحیح ذخیره می‌شوند.
- انتقال بین حساب‌ها درآمد یا هزینه محسوب نمی‌شود.
- از منوی «پشتیبان‌گیری» می‌توانید نسخه SQLite و CSV تراکنش‌ها را دریافت کنید.
- برای امنیت بیشتر، فایل `storage/.htaccess` و `storage/index.html` برای جلوگیری از دسترسی مستقیم در هاست‌های Apache قرار داده شده‌اند. در Nginx یا برخی تنظیمات هاست، پوشه `storage` را بیرون از web root قرار دهید یا دسترسی مستقیم آن را از پنل هاست مسدود کنید.
- این نسخه تک‌مدیره است و برای استفاده عمومی روی اینترنت، حتماً HTTPS را فعال کنید.

## تغییرات رابط کاربری
- کارت‌های بانکی قابلیت ویرایش و حذف دارند؛ کارت دارای تراکنش/انتقال برای حفظ سوابق حذف نمی‌شود.
- ثبت درآمد/هزینه، افزودن کارت بانکی و انتقال وجه در پنجره‌های مودال انجام می‌شود.
- منوی سمت راست با آیکون‌ها و دکمه باز/بسته‌شدن شبیه پنل مدیریت وردپرس طراحی شده است.

### به‌روزرسانی رابط کاربری
- فونت Vazirmatn و جهت راست‌به‌چپ منوها با آیکون در سمت راست.
- مدیریت دسته‌بندی‌های درآمد و هزینه از زیرمنوی «ثبت درآمد و هزینه».
- انتخاب تاریخ با تقویم شمسی جلالی.
- جداکننده سه‌رقمی مبالغ و نمایش مبلغ به حروف در زیر فیلدهای مبلغ.
- در فرم انتقال، انتخاب شماره کارت یا شبا و ثبت نام صاحب کارت/حساب؛ این اطلاعات در فهرست انتقال‌ها نیز نمایش داده می‌شوند.
